# Contributing

Thanks for helping MochaTidal. It is a CSS theme for TIDAL through TidaLuna, so fixes are usually small and visual.

## Ways to help

- Report selectors that break after TIDAL or TidaLuna updates
- Send CSS fixes
- Share screenshots of anything that looks off

## Getting set up

No build step. Edit the CSS and reload. The theme needs the TidaLuna Themer plugin and is verified against TIDAL desktop 2.43.2 with TidaLuna 1.17.1-beta.

## Checks before a pull request

- Screenshot before and after your change
- Check the main window plus floating panels like the queue and lyrics

## Where to submit

Open issues and pull requests in this repository.
